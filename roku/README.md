# MuGa TV para Roku

Misma cuenta del proveedor que la app de Android TV. GitHub genera `MuGaTV-Roku.zip` en cada versión:
https://github.com/juliomunozmartinez-oss/mi-tv/releases/latest/download/MuGaTV-Roku.zip

## Instalar (modo desarrollador)
1. En el control del Roku: Inicio ×3, Arriba ×2, Derecha, Izquierda, Derecha, Izquierda, Derecha.
2. Acepta, pon una contraseña y anota la dirección que aparece (p. ej. http://192.168.1.45).
3. Desde un celular o computadora en el mismo Wi-Fi abre esa dirección, entra con usuario `rokudev`
   y tu contraseña, sube `MuGaTV-Roku.zip` y toca **Install**.

## Qué trae (versión 1)
Perfiles con avatares, Inicio con destacado y filas, TV en vivo (México primero, ▲▼ para cambiar de canal),
Películas, Series con episodios, Seguir viendo, Mi lista y siguiente episodio automático.
Las categorías se cargan conforme se acercan a la pantalla (Roku tiene poca memoria).
